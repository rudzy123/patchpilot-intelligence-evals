- Do not read or modify the local `patchpilot` or `neural-from-scratch` repositories.

The only exception is an operator-approved Track 8A transfer of the exact URLs in the committed acquisition plan, written outside this repository. CI does not run that transfer. A session that has not received the explicit plan approval in chat does not start it.
